# Changelog

## 1.0.1

- First release published from the registry. Adds the packaging metadata a catalog entry
  needs — declared core and PHP compatibility, `LICENSE`, `README.md` and a `.distignore`.
  No change to the plugin's behaviour.

## 1.0.0

- Initial release: placement context registration, per-context field filtering, submission veto
  (spam-word example), validation-errors filter (no-op example), and a `form_submitted` logger.
